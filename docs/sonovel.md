# So Novel 适配

版本 v0.1.0，最低聚阅版本 1.4.0。无需更新应用本体。

## 使用

在平台安装「So Novel 多书源」，进入发现页的小说分类。默认首页汇集三个书源的推荐，搜索会查询默认规则集中的 13 个书源；选择具体书源后，首页和搜索使用该书源。清空关键词后可重新选择书源。也可在搜索框粘贴已支持书源的作品详情页链接。

可查看作者、封面与完整目录，点击作者搜索同书源的其他作品。章节支持分页合并及现有本体的小说阅读、进度保存和缓存。不同书源的同一本作品保留各自地址，避免目录和进度混用。

## 移植范围

参考项目：[freeok/so-novel](https://github.com/freeok/so-novel)，固定版本 [88acec6ee489ca1c2489c624cedd1ef417d3f3ee](https://github.com/freeok/so-novel/tree/88acec6ee489ca1c2489c624cedd1ef417d3f3ee)。移植其 `bundle/rules/main.json` 默认规则集及解析流程，不依赖安装 Java、部署 WebUI 或额外服务器。

默认规则集包含香书小说、书海阁小说网、梦书中文、鸟书网、笔尖中文、悠久小说网、阅读库、笔趣阁365、第八中文网、笔趣阁52、少年小说网、新笔趣阁小说网、笔趣阁info。首页聚合选择书海阁、第八中文和笔趣阁info，单次最多三个书源并行，减少初次加载开销。

原项目的 TUI、整书导出 EPUB/PDF、简繁转换及其他可选规则集未移植。来源阅读与缓存由本体承担；不接入外部 Cloudflare 代验证服务，不执行规则或网页中的任意 Java/JavaScript。默认书源按上游大陆 IP 使用场景请求直连；VPN 的系统路由仍由设备和代理工具决定。

## 实现与限制

- 本地内置规则，不从远端下载可执行代码。上游的简单字段处理、onclick 目录与 base64 正文已改为明确的数据解析。
- 修正笔尖中文和鸟书网的作品路径；表格搜索结果补齐 HTML5 上下文，避免解析独立 tr 时丢失字段。
- 同一书源请求串行并限速，相同请求合并，成功网页短暂复用。笔趣阁365搜索至少间隔 15 秒，少年小说网至少 20 秒。
- 搜索按需翻页；目录去重时保留完整列表中的后一次位置，避免“最新章节”预览把章节提到开头。目录最多读取 80 页，慢响应总耗时超过 90 秒会明确失败，不返回部分目录；章节最多 20 页，正文超过 2 Mi 字符停止读取。
- 只跟随当前章内分页，不继续吞入下一章。循环分页、明确提示未完却缺少下一页链接、空正文和验证页均报错，不以成功结果交给缓存。
- HTML 缓存最多 24 项且总计不超过 6 Mi 字符。失效/被验证页面不缓存。
- 源站可能超时、返回 502、限制搜索或更改页面。部分聚合源失败时保留其他源结果；全部失败会报错。无访问权限或付费章节不解锁。
- 原站未提供相应数据时不显示封面；不额外调用其他网站补封面，也不虚构评论接口。

## 许可

适配及原始规则沿用 AGPL-3.0-only。上游作者 pcdd / freeok 及贡献者的出处保留在脚本头部。完整许可位于 `licenses/so-novel-AGPL-3.0.txt`，也嵌入单文件脚本以便独立分发。原始规则快照位于 `fixtures/sonovel/main.json`；重生成命令 `node tools/update_sonovel.mjs`。更新规则时须同时核对上游版本、脚本头部和适配逻辑。

## 验证

离线测试使用原创 HTML 与真实 HTML5 DOM 解析，不访问源站：

```sh
python -m pip install -r test-requirements.txt
node --test tests/sonovel_test.mjs
python -m unittest discover -s tools -p 'test_*.py'
python tools/build_repository.py
```

24 项测试覆盖规则与许可、地址限制、表单编码、推荐列表、聚合容错、搜索分页与并发、作者字段、完整目录、隐藏目录条目、base64 中文、章内分页、残缺正文、验证页面及限速。

2026-11-01 联网检查：11 个书源已完成首页、搜索、详情、完整目录与首章正文的链路检查；作品章节数介于 17～3293，正文只检查段落及字符数量，不保存或公开作品文本。笔趣阁52在当前线路持续超时；新笔趣阁小说网首页偶发连接失败，首页/搜索曾正常返回，完整链路尚未通过。第八中文网首次连接失败，稍后复测通过。以上是当时当前线路的结果，不代表所有网络均可用。

可手动复测指定书源：`node tools/check_sonovel.mjs bqg-info`；默认检查三个聚合首页书源。`node tools/sonovel_preflight.mjs` 仅检查默认书源首页及搜索。联网检查不在 GitHub Actions 中运行，输出只有状态和数量。

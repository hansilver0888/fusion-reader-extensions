# 4KHD 圖集 v1.1.0

2026-10-30 核对站点（WordPress 站点，本身链接指向同一套内容的 `www.4khd.com`，镜像域名当期是 `https://vxhh.uuss.uk/`），完成单文件插件。只读取公开的列表页、搜索页和公开接口，不登录、不写入、不调用广告或推广接口。

## 站点结构

| 能力 | 实现方式 |
| --- | --- |
| 精选列表 | 站点自带的分页页 `/pages/album`（最新）、`/pages/popular`（熱門）、`/pages/cosplay`，每页 12 项，翻页参数 `?query-3-page=N` |
| 分类 | 公开接口 `/wp-json/wp/v2/categories` 给出 5 个分类（photo、cosplay、miscellaneous、bare、popular），列表用 `/wp-json/wp/v2/posts?categories=<id>` |
| 搜索 | `/search/<关键词>`，翻页 `/search/<关键词>/page/N` |
| 作品 | 公开接口 `/wp-json/wp/v2/posts?slug=<slug>` 返回标题、封面、观看数、分类、摘要和正文 |
| 图片 | 正文里的图集地址，由 `i0.wp.com`（Jetpack/Photon 缩略服务）转发到 `pic.4khd.com` |

三处需要按站点特性处理：

- **分页作品**：站点用 WordPress 的 `<!--nextpage-->` 把大图集切成多页。公开接口保留该标记并返回**全部**页的正文，因此一次读取就能得到完整目录，插件据此把作品拆成「第 N 部（X 張）」多集，不额外请求分页 URL。
- **接口频率限制与参数限制**：`/wp-json` 被 nginx 限速，且带 `_fields` 参数的请求直接返回 403（`orderby=views` 返回 400）。因此列表页走站点 HTML（12 项/页，约 98 KB），接口只用来读分类列表和单个作品；被 403 / 429 拦下时先等 2.5 秒重试一次，仍失败则提示稍等 20 秒。
- **镜像域名会轮换**：旧地址不再提供内容，而是 302 到一个落地页（`/4khd.php`），落地页里的脚本带着当期候选清单，例如 `const sites = [ 'https://vxhh.uuss.uk', 'https://hfjsg.ssuu.uk' ];`，逐个探测各自主机的 `/favicon.ico` 后再跳转。

## 镜像域名自动切换（v1.1.0）

插件不再把入口写死，启动时按下面的顺序解析一次：

1. 插件设置里的「站點入口」（可手动填 `https://vxhh.uuss.uk` 这类地址，留空表示自动）；
2. 内置的已知镜像：`vxhh.uuss.uk`、`usti.uuss.uk`、`hfjsg.ssuu.uk`；
3. 如果某个候选返回的是落地页，就从页面里的 `sites = [...]` 取当期候选继续试。

判定「可用」的标准是候选主机的 `/wp-json/wp/v2/categories?per_page=1` 返回 JSON 数组（约 3 KB，顺带验证接口可用），不是则视为已迁移。选中的地址会被写回「站點入口」设置，下次启动直接使用；浏览过程中如果某个页面突然变成落地页，插件会清掉入口、重新解析并重试一次，所以后续再换域名也不需要重装插件。

只接受 `*.uuss.uk`、`*.ssuu.uk`、`4khd.com` 这几个家族的主机（设置里手填也一样），避免把请求发到任意地址。列表与作品链接里的 `www.4khd.com` 会改写到当期镜像；图片域名保持原样。图片地址不加 Referer 也可读取，把 `?w=` 调大会被 429 拒绝，所以一律按站点给出的地址使用。


## 已支持

- 8 个分类入口：最新、熱門、Cosplay 精選，以及 photo / cosplay / bare / miscellaneous / popular 五个真实分类（标题带作品数量）。
- 列表与搜索分页；标题、封面、日期与观看次数作为列表摘要。
- 作品详情：标题、封面、观看数、分类名、摘要，以及按图片数量标注的目录。
- 阅读：按集返回图片地址（多部作品逐部返回，越界时取最后一部）。
- 读取节流：请求串行且间隔不小于 300 毫秒，相同读取合并，结果缓存 30 秒，被限速后退避 20 秒。

## 尚未支持

- 站点账号相关功能（收藏、下载券、TeraBox 提取码）保持只读，不做。
- 站点若把图片换成需要 Referer 或签名的地址，需要再核对；当前实测无需额外请求头。

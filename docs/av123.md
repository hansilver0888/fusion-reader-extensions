# 123AV v1.0.0

2026-10-31 实测 `123av.com`，完成单文件插件。验收基准是**番号 `SNOS-378`**：搜索能命中、详情能打开、播放能出 HLS 并取到分片。

## 为什么选它

| 站点 | 番号可查 | 播放 | 结论 |
| --- | --- | --- | --- |
| `jable.tv` | — | — | 整站 Cloudflare 403（只有 `robots.txt` 200） |
| `supjav.com` / `javhdporn.net` / `javmix.tv` | — | — | Cloudflare 403 |
| `javgg.net` / `sextb.net` | — | — | 自定义挑战 / 地区限制 |
| `eporner.com` | 否（西文为主） | 需播放器签名 | 不入库 |
| `xhamster.com` | 否（非番号库） | 可播 | **已归档**（`archive/xhamster/`） |
| **`123av.com`** | **是**（`/en/search?keyword=SNOS-378`、`/en/v/snos-378`） | 嵌入页 `/stream?id=` 直出 m3u8 | 采用 |

## 站点结构（2026-10-31 实测）

| 能力 | 实现方式 |
| --- | --- |
| 分区 | `/en/new`、`/en/hot`、`/en/uncensored`、`/en/uncensored-leaked`，分页 `?page=N` |
| 搜索 | `/en/search?keyword=<关键词或番号>`，分页 `&page=N` |
| 作品页 | `/en/v/<slug>`，slug 就是番号（如 `/en/v/snos-378`） |
| 卡片 | `div.card`：`a.card__cover[href]`、`img.card__img`（`icdn.123av.me/img2/s360/<slug>/cover.jpg`）、`span.card__dur`、`<h3>` 标题 |
| 详情 | `<title>` 取标题，封面取 `icdn` 的 `s500` 大图；简介取 `watch__desc`，没有则留空（站点 `meta description` 是通用文案，已过滤） |
| 播放 | 作品页把分集列表打包成 `player(JSON.parse('…'), …)`；嵌入页（`sadie-shop.site/e/<hash>`）的 `/stream?id=<hash>` 返回 `media.stream`（m3u8） |

嵌入域名会变（`sadie-shop.site`、`streamtape` 等），所以 origin 从分集地址里取，不写死。

## 已支持

- 4 个分区 + 关键词/番号搜索，均分页。
- 列表：标题、封面、时长。
- 详情：标题、封面、简介；目录按线路列出（通常 1 条，多条时用 `#epN` 区分）。
- 播放：分集 → 嵌入 `/stream?id=` → HLS，带嵌入域名的 `Referer`。
- 读取节流：请求串行且间隔不小于 300 毫秒，页面缓存 30 秒；不使用 `URL` 等 QuickJS 里没有的宿主对象。

## 未支持

- 评论、收藏、下载、账号功能不做。

- 新增 7 项离线测试，仓库合计 140 项通过；覆盖分区/搜索路径与分页、卡片解析与去重、标题与 `s500` 封面、打包分集解包（`\u0022` / `\/`）、嵌入流转 HLS 与 Referer、无线路/坏 JSON/空 media 的报错、作品地址校验。
- 线上实测（`node tools/check_av123.mjs`，5 次插件请求）：

```
最新第 1/2 页       → 各 12 条，且两页不同
```

- 仓库索引生成与脚本大小、SHA-256 检查通过。


联网测试独立于 CI，不把页面或播放地址保存到仓库；离线测试使用原创占位 HTML，只沿用站点 URL 形状、类名与元数据字段名。站点结构、番号命名与嵌入域名都可能变化，实际结果以设备测试为准。

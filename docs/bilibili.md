# 哔哩哔哩收藏夹

版本 v0.1.0，最低聚阅版本 1.4.5。插件独立维护，应用不内置站点代码或登录信息。

## 使用

1. 在扩展页安装并启用插件，点击「来源登录」。
2. 使用哔哩哔哩手机客户端扫一扫并确认登录。若在同一部手机操作，可先截图二维码，再在手机客户端从相册识别；回到聚阅后继续确认登录状态。
3. 在「发现 → 动画」选择来源及收藏夹。搜索仅查找个人收藏的视频。
4. 在详情页选择分 P 播放；播放器已有清晰度、弹幕、评论、续播和缓存入口。

二维码及登录凭据不通过第三方制图服务，客户端本地绘制二维码。会话由应用提供的、按插件隔离的受保护存储保存，不写入普通插件设置、JSON 导出或云端同步。退出来源账号只清除当前设备会话，不操作哔哩哔哩的收藏、点赞或评论。

## 范围和限制

- 读取自己创建的收藏夹和其中的视频；不提供公开推荐、全站搜索、稍后再看或订阅合集入口。
- 分 P 采用视频 BV 号和 CID，播放、弹幕随当前分 P 切换；视频评论在各分 P 之间共用，支持分页、置顶、图片和楼中楼回复。
- 播放地址使用当前账号的正常访问权限；音视频分离的 DASH 地址交由本体合并播放。优先选择 AVC 视频和 AAC 音频，并只展示接口当前允许的清晰度。单段旧格式可播放，旧式多段 durl 暂不支持。
- 不解锁会员、付费、地区或失效内容。视频不可访问、登录过期和接口限制时给出相应提示。
- 弹幕使用当前 CID 的 XML 弹幕池，支持压缩响应；不保证包含全部历史弹幕，也不发送实时弹幕。
- 收藏夹为空、视频被删除、评论关闭或未提供弹幕均可能使对应区域为空。
- 第三方接口变化可能需要单独更新插件。扫码登录为本体新增公共能力，旧版应用不能加载本插件。

## 接口与实现参考

直接访问哔哩哔哩官方站点的只读接口，登录二维码由官方 passport 接口生成和确认：

- `x/passport-login/web/qrcode/generate` / `poll`：网页扫码登录。
- `x/web-interface/nav`：当前登录身份校验。
- `x/v3/fav/folder/created/list-all` / `x/v3/fav/resource/list`：收藏夹和收藏视频。
- `x/web-interface/view`：视频详情和分 P。
- `x/player/playurl`：当前可播放清晰度与音视频轨。
- `comment.bilibili.com/{cid}.xml`：当前分 P 的弹幕池。
- `x/v2/reply` / `x/v2/reply/reply`：视频评论与回复。

请求字段核对参考 [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus) 当前实现的 `lib/http/api.dart`、`fav.dart`、`reply.dart`。未引入第三方签名密钥，不依赖已关闭的 API 文档仓库。

## 验证

独立离线测试：`node --test tests/bilibili_test.mjs`。覆盖扫码等待/确认/过期/取消、并发取消时凭据回滚、账号校验、Cookie 解析、收藏夹分页与过滤、仅个人收藏搜索、分 P、清晰度及独立音轨、Cookie 不传给媒体 CDN、评论大整数 ID 和回复分页。

目录构建：`python -m unittest discover -s tools -p 'test_*.py'` 与 `python tools/build_repository.py`。

匿名联网已核对官方扫码接口、身份接口、视频详情、正常播放信息、压缩 XML 弹幕及评论的返回结构。真实账号收藏夹及登录后的连续播放需由使用者扫码后验收；仓库不保存任何真实凭据、账户信息或作品内容。

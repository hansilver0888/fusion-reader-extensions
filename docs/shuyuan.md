# 书源引擎（阅读·Legado 书源）

版本 v0.1.0，最低聚阅版本 1.4.0。无需更新应用本体。

## 使用

在平台安装「书源引擎」，进入该插件的设置：

- **书源 JSON 地址**：阅读（Legado）格式书源合集的直链，默认使用
  `shidahuilang/shuyuan-bak` 的验证书源 `good.json`（约 16 MB，每 3 天自动校验更新，首次加载较慢）。
  也可改填任意 Legado 书源数组链接，或本机导出的单源/多源 JSON；GitHub 文件页地址会自动转为 raw 直链。
- **书源名称**：要使用的书源名称或其片段（如「速读谷」，也可填域名片段）。留空则使用列表中第一个可用书源。

配置完成后：发现页显示所选书源的探索分类（探索页 URL 中的分类），搜索走所选书源，在搜索框粘贴
作品详情页链接可直接定位打开。换书源时只改「书源名称」，书架上的旧链接仍按域名匹配回各自的书源，
目录与阅读进度不会串源。

## 数据来源与移植范围

参考项目：[shidahuilang/shuyuan-bak](https://github.com/shidahuilang/shuyuan-bak)（GPL-3.0，书源规则版权归各书源作者）。
该项目用 GitHub Actions 定期校验并合并全网书源，产出 `good.json` 等文件。

本插件**不内置任何书源数据**，也**不复用上游代码**：书源规则是用户自行配置地址下载的声明式数据，
解析器为本仓库原创实现。插件本体只有十几 KB，书源随上游自动更新，无需重新发版。

## 实现与限制

支持的规则子集（覆盖大量纯规则书源）：

- 默认 jsoup 语法：`class.xxx`、`tag.xxx`、`id.xxx`、裸标签、`.N` / `.-1` / `.N:M` 索引、
  `text.关键词` 文本链接匹配、`@text` / `@textNodes` / `@html` / `@href` / `@src` / `@content` 等取值；
- 原生 CSS 选择器（含 `>`、`,`、属性选择器，`:contains()` 与 `:eq(N)` 由插件后置过滤）;
- XPath 子集：`//tag[@attr='v']`、`[contains(text(),'x')]`、`[last()-N]`、`/text()`、`/@attr`；
- JSONPath 子集：`$.a.b`、`$['a-b']`、`[0]`、`[*]`（含 `[*]` 之后的字段映射）；
- `##正则##替换###标志`、`{{baseUrl}}` / `{{key}}` / `{{page-1}}` 等模板（仅四则运算，不执行任意表达式）、
  `&&` 合并与 `||` 兜底、`@put` / `@get` 变量、`<a,b>` 按页变体段、搜索地址后缀的 `,{...}` 选项
  （method / body / headers / charset 声明）、`exploreUrl` 的 `分类::地址` 与 JSON 数组两种写法。

安全边界（与本仓库一贯原则一致）：

- **不执行书源或网页中的任何 JS/Java 片段**。含 `<js>`、`@js:`、`java.*`、`jsLib`、`webView` 等标记的书源
  在加载时被整源过滤，既不解释也不运行；此类源在 `good.json` 中占比不小（聚合 API 源、番茄/七猫系大多依赖签名脚本）。
- 列表与正文只按声明式规则解析，不读取本地凭据，不打开 WebView，不注入 Cookie。

当前不支持：登录类书源、验证码/验证页、CookieJar 持久化、`gbk/gb2312` 等非 UTF-8 编码的搜索参数、
`imageStyle`、下载源（`bookSourceType` ≠ 0）、漫画/音频源，以及 `@@` 之外的内嵌脚本模板。
目录最多读取 150 页 / 8000 章，正文最多合并 20 个分页，分页请求间等待 120 ms；书源列表缓存 30 分钟。

源站可能失效、限流或改版：`good.json` 已过滤校验失败的书源，但仍可能出现详情页可取、正文取不到的情况，
此时插件给出明确错误而不是把残缺内容交给缓存。搜索、发现与阅读的多本书源失败互相独立。
`@html` 取元素外层 HTML（宿主的 `content` 语义），与 Legado 的内层 HTML 略有差异，正文解析不受影响。

## 许可

解析器与适配代码为本仓库原创，采用 MIT。分发的书源规则属于第三方数据，版权归各书源作者，
使用者需自行确认来源与合规性；上游 shuyuan-bak 仓库采用 GPL-3.0。

## 验证

离线测试使用原创书源与原创 HTML，经真实 HTML5 解析，不访问源站：

```sh
python -m pip install -r test-requirements.txt
node --test tests/shuyuan_test.mjs
python -m unittest discover -s tools -p 'test_*.py'
python tools/build_repository.py
```

18 项测试覆盖：发布元数据与「无动态代码执行」约束、脚本依赖/停用/非文本/无正文书源的过滤、
列表缓存与 GitHub 页面链接转换、书源选择、模板四则运算与按页变体、GET/POST 搜索与关键词编码、
jsoup 默认语法与正则净化、JSONPath 接口源全链路、探索分类与分页、目录分页与去重与环检测、
章节正文合并与 replaceRegex 与回链终止、XPath 下一页、`@put/@get` 变量、粘贴链接打开、规则辅助函数容错。

联网检查（由维护者手动执行）：把「书源名称」逐个切换为实际书源，检查发现页、搜索、详情目录、首章正文；
`good.json` 中字典型书源以 HTML 规则源为主，建议优先选用校验通过且不含脚本的站点。
